# 交互迁移对照（2026-11-11）

| 新参考交互 | React / Java 实现 |
| --- | --- |
| 项目总览、进入项目 | `/`、`/projects/:id`；持久化交付目标、负责人、截止、归档 |
| 我的待办、等待系统 | `/tasks`；按当前账号责任人筛选，活跃制作任务单独派生系统等待 |
| 分工、批量分配 | 作品 workflow，支持备注、时间码、责任人、截止与 revision 条件写入 |
| 生成任务 | `/queue`；沿用真实 FFmpeg 作业，不将接力或重试计为新作品 |
| 快捷制作 | `/content`、`/studio`；三阶段与实际素材预览 |
| 样片广场、换我的商品 | `/gallery`；9 个结构配方、品类/收藏筛选、不继承示例事实 |
| 改这镜 | 方案镜头行 + 单镜编辑弹窗，其他镜头保持，锁定镜头不可误改 |
| 单镜参考改编 | `/reference`；来源切点与目标镜头明确选择，只替换画面安排 |
| 场景变体 | 单作品创建 1–3 条新草稿，记录来源与版本，不自动调用模型 |
| 保存冲突 | 真实后端 revision 409，保留编辑并提供读取新版/另存副本 |
| 客户知识、资源中心 | 沿用规则/配方与真实文件服务，资源页提供统一二级导航 |
| 团队与费用 | 分工联系人持久化、明确真实生成配置与费用边界；没有伪造角色登录 |

技术栈仍为 React + TypeScript、Java 17 + Spring AI、Docker；参考代码 `xinliu/` 未修改。V2 迁移保留原有作品与媒体，主服务依然使用原配置、登录和客户权限。

当前差异：尚无跨账号共享项目、服务端团队邀请/角色授权或外部分享令牌；付费生成与平台接口仍需真实供应商配置。样片是拍法结构，不代表模型已经生成过相应画面。

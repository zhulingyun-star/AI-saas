最短测试路径

上传真实商品 → 确认方案 → 准备视频出片 → 上传素材与获取报价 → 明确授权模型调用 → 查单 → 结果带回当前作品审片。

接口用途是否调用模型
POST /api/session本地会话，返回CSRF否
GET /api/config非敏感配置状态否
POST /api/prompts/compile品类/拍法/功能Prompt否
POST /api/assets文件或公网URL否
POST /api/tasks输入快照与幂等草稿否
POST /api/tasks/{id}/quote验证能力与配置估价否
POST /api/tasks/{id}/submit需authorized=true、报价、费用与上限是，可能收费
POST /api/tasks/{id}/refresh查已有任务，不重新生成不创建生成，查单按供应商条款
GET /api/tasks/{id}/result已转存真实视频，支持Range否

接入配置

复制 backend/provider.example.json 为 backend/provider.local.json，填真实URL、创建/查询路径、模型ID、响应字段映射、能力与报价。密钥在 backend/.env.local 或启动环境中，浏览器不保存密钥。

xinliu-bridge 是本系统的适配契约，不是Seedance官方接口。供应商结构不同时，通过 requestTemplate 字段映射适配，或实现专用供应商适配器。不能把示例路径直接拿去请求官方。

{
  "model":"真实模型ID",
  "client_task_id":"心流任务ID",
  "capability":"commerce",
  "prompt":"本条确认的提示词",
  "duration":15,
  "aspect_ratio":"9:16",
  "resolution":"1080p",
  "assets":[{"role":"product_image","url":"授权HTTPS或受支持的data URI"}]
}

关键限制

本地上传16MB，结果转存120MB；本机视频URL不能被外部模型读取，请提供授权公网HTTPS URL。动作迁移必须同时有商品图、人物图、动作视频和供应商motion能力。报价未知不提交，超时未知不自动重发。所有识别、编导和视频调用都需要各自确认费用。

当前是单操作者回环测试服务，不是生产多租户、多人授权或计费系统。视频只检查文件标识，内容、规格和营销依据仍需人工审核。

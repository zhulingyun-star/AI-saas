出片API联调

OpenAPI JSON · 健康检查

本地单操作者联调服务。审核副本未配置真实供应商；生产能力以当前接口状态与供应商权限为准，不用历史调用记录代替当前配置。

视频制作

上传真实商品 → 确认方案 → 准备视频出片 → 上传素材与获取报价 → 明确授权模型调用 → 查单 → 结果回到对应作品待审片。默认4秒、480p、无声、单镜头，不自动批量生成。

接口用途模型调用
POST /api/session本地会话与CSRF，不是团队登录否
GET /api/config非敏感配置状态否
POST /api/prompts/compile品类、拍法、功能独立Prompt否
POST /api/assets客户范围内的文件或授权公网URL否
POST /api/tasks输入快照与幂等草稿否
GET /api/tasks?clientId=客户ID该客户最近100条任务否
POST /api/tasks/{id}/quote验证能力与配置估价否
POST /api/tasks/{id}/submit需要authorized=true、报价、费用与上限是，可能收费
POST /api/tasks/{id}/refresh查询已有任务，不重新生成不创建生成；查单按供应商条款
GET /api/tasks/{id}/result已转存真实视频，支持Range否

视频理解与知识提炼

客户知识 → 素材提炼 → 选择1–5条已评价视频 → 核对处理授权 → 准备各条估价 → 确认本次费用 → 逐条分析。结果保存为知识草稿，核对发布、明确选用版本后才能用于新方案。

复用任务接口，设置kind为vision、input.config.videoAnalysis=true、assets职责为reference_video。供应商必须为gemini-content且显式支持supportsVideoDataUri。本地视频上传后由服务端转inline_data，硬上限16MB，可设置更低上限。不把blob链接或任意网址当作Gemini fileUri。

Yunxin通过YUNXIN_VIDEO_ANALYSIS_INLINE=true显式开放能力，默认false。密钥只在服务器；估价未知、能力未配置、文件缺失或超限均拦截。截断和空答案保留不确定状态，不自动采用或重发。

供应商配置

Yunxin与SilvaMux分别配置文本、图片理解和视频。使用XINLIU_TEXT_PROVIDER / XINLIU_VISION_PROVIDER / XINLIU_VIDEO_PROVIDER选择渠道。配置和限制见仓库backend/PROVIDERS.md、backend/SILVAMUX.md。

沿用backend/.env.local和backend/.env.yunxin.local或启动环境变量；凭据不进浏览器。自定义backend/provider.local.json优先于环境配置，需提供独立keyEnv、真实URL、模型ID、能力声明与报价。

xinliu-bridge是本系统的适配契约，不是Seedance官方接口。供应商结构不同时需要字段映射或专用适配器，不能直接请求示例路径。

{
  "model": "真实模型ID",
  "client_task_id": "系统任务ID",
  "capability": "commerce",
  "prompt": "本条确认的提示词",
  "duration": 4,
  "aspect_ratio": "9:16",
  "resolution": "480p",
  "assets": [{"role": "product_image", "url": "授权HTTPS或受支持的data URI"}]
}

SilvaMux视频使用Ark协议和服务器SILVAMUX_API_KEY。Yunxin文本、视觉与视频凭据分开。估价与有声/参考模式单独配置，未知报价不套用无声基础价。结果origin白名单核对后才能转存，补充白名单可继续查单，不重复生成。

团队归属与边界

input.config.teamId保存任务创建时的团队归属，返回task.teamId；历史无团队任务不自动归入当前团队。团队费用页面显示当前可访问客户最近100条任务的估价记录，不是全量费用报表或供应商实际结算。

页面团队范围与个人授权取交集，但本地会话不是服务端多人登录或多租户鉴权。项目、作品、产单、模型任务仍分别管理。团队计划预算不是钱包，不提供支付充值功能。

调用限制

本地上传16MB，结果转存120MB。视频生成的参考文件仍需授权公网HTTPS URL；视频理解的inline例外仅在供应商显式支持时开放。动作迁移必须具备商品图、目标人物图、动作视频和供应商motion能力。

明确HTTP拒绝返回rejected；网络超时或不完整响应保留unknown，不自动重发。所有视觉识别、文本和视频调用分别授权；估价上限不是供应商强制扣费上限。营销依据、内容、画面质量和交付规格仍需人工审核。

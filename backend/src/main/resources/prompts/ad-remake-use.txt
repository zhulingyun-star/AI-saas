你是电商广告的产品导演。上面给了你**用户这件商品**的图与描述,
以及一条参考广告片**逐镜**拆出来的「这一镜商品怎么露、怎么被用」。

你要一次产出两样。

## 一、使用方式卡:这件商品到底怎么用

五项,一项都不许空。**每一项都要标来源**,三选一:`来自描述` / `从图推断` / `未知`。

| 键 | 写什么 |
|---|---|
| `form` | **形态**:它是什么形状的东西,多大,几个部件,材质看起来是什么 |
| `open` | **开合方式**:怎么打开/关上(拧盖 / 拉环 / 按压 / 翻盖 / 磁吸 / 系带 /
  根本不用打开…)。用你自己的话写,**没有清单可挑** |
| `moving` | **可动部件**:哪几处会动、怎么动(盖子旋转、鞋舌翻起、表带扣合…);
  一处都不动就如实写 |
| `hold` | **穿戴或握持方式**:人拿它的哪一处、用几根手指、穿在身上哪里、放在哪里 |
| `use` | **典型使用动作**:一个人真正用它的时候,手怎么动、身体怎么配合,从头到尾是哪几下 |

🔴 **商品描述里写了的以描述为准**,描述没写才从图推断,图上也看不出来就写 `未知`
—— **别编**。标了 `未知` 的项,下面第二样里就别拿它去换动作(那是拿猜出来的东西
去改一条真花钱的片子)。

## 二、差异对照表:参考片那一镜的做法,换成我们的怎么做

参考片**每一镜**给一行(镜号一一对应,一镜都不许少、不许合并)。
每行四样:

| 键 | 写什么 |
|---|---|
| `idx` | 镜号(照抄) |
| `ref` | 参考片这一镜**商品怎么露、怎么被用**,一句话(从上面给你的原文里提炼,别发挥) |
| `verdict` | 三选一:`照搬` / `换动作` / `换部位` |
| `ours` | **我们这件商品在这一镜的对等做法**,一句话。写得具体到"手怎么动" |
| `why` | 为什么这么判,一句话 |

三种结论各是什么意思:

· **照搬** —— 这一镜的做法我们这件商品原样能演(静置特写、人走过、纯环境镜、
  只是被拿在手里)。`ours` 仍要写清楚**换成我们的商品**之后画面上是什么;
· **换动作** —— 露的部位对得上,但**打开/操作的方式不同**
  (参考片拉易拉罐的环 → 我们是拧瓶盖;参考片按压泵头 → 我们是翻盖);
· **换部位** —— 参考片特写的那一处我们这件商品**根本没有**,要找**功能对等**的另一处
  (鞋头包边 → 杯口密封圈;鞋侧图案 → 瓶身标识区)。

🔴 **秒数原样照抄,一个数都不许改** —— 动作换了也要在**原来那几秒里演完**。
拧盖比拉环慢,那就演「拧开那一瞬」,别把镜头拉长。这一条写进 `why` 里提醒自己。

🔴 **没有对等物的镜**:按这件商品**最接近**的用法演,写清楚你选了哪一种、为什么。
别写「无法对应」—— 那一镜照样要出画面。

## 三、输出

**只输出一个 JSON**,不要解释、不要代码围栏以外的任何字:

```json
{
  "usage": {
    "form": {"text": "…", "src": "来自描述"},
    "open": {"text": "…", "src": "从图推断"},
    "moving": {"text": "…", "src": "从图推断"},
    "hold": {"text": "…", "src": "来自描述"},
    "use": {"text": "…", "src": "从图推断"}
  },
  "diffs": [
    {"idx": 1, "ref": "鞋头包边正对镜头占画面主体",
     "verdict": "换部位", "ours": "杯口密封圈正对镜头占画面主体,拇指压在圈沿上",
     "why": "我们这件没有鞋头,功能对等的密封处是杯口那一圈;秒数照抄 0~1.2s"}
  ]
}
```

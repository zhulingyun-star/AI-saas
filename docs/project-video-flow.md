# 从项目开始制作视频

## 新版项目（2026-11，V10）

顶部「项目」栏目现在直接列项目：一个项目 = 一个商品 + 一种创作方式（就是原来的「作品」，`projects` 一行），不再经过交付项目。

1. 项目列表（`/`）：左栏文件夹（规则同商品库，最多两层），可搜索、改名、移动。视频二创项目进新版详情 `/p/{id}`；框架模式、一键成片和以前的作品暂时进原来的制作页。
2. 新建项目（`/p/new`）：选商品（弹窗：左文件夹、右搜索，可在弹窗里新建商品并同步到商品库）→ 创作方式（视频二创 / 框架模式 / 一键成片，剧情模式即将开放）→ 视频二创选一条已拆解的参考视频（参考视频选择弹窗）→ 画幅（竖屏 9:16 / 横屏 16:9）、分辨率（480p / 720p / 1080p）、项目名、放进哪个文件夹 → 核对商品事实。不选发布平台和时长；创建不提交任何生成任务。参考视频详情的「用它新建项目」会带着这条视频进来。
3. 视频二创详情四步：商品 → 方向（参考视频的结构、开头类型、改编思路、给谁看——人群取自商品库）→ 分镜（每镜「原视频 | 改成」对照，改成的机位 / 画面 / 台词可编辑保存，台词可增删，每镜任务默认来自参考视频库的标注、可在这里改；顶部转化结构和广告用语检查都只提醒不拦）→ 出片。确认 / 下一步 / 出片按钮都在步骤条下方的置顶操作条里；分镜确认之前不出现成片画面。
4. 出片：确认后按分镜拼出分段出片词，走原来的任务提交和轮询（`jobs` / `JobWorker`），画幅和分辨率随任务快照传给视频接口。可出很多版：每版记下当时的出片词、画幅分辨率、改动说明；单独审片（好 / 差必填原因 / 可投放 / 不用了），「差」的原因自动带进下一版；「改这一版再出」可以一句话让 AI 改（需文字模型）或按段直接改；生成中显示真实阶段（排队 → 交给视频接口 → 生成中）和已等待时间，可取消；两版并排对比；「基于这条再做一条」四个入口（商品资料里没有价格时「换价格说法」不可用）。
5. 交付项目（`campaigns`）的数据和接口都保留，旧页面在 `/campaigns`、`/projects/{id}`；新建的项目不挂交付项目。旧流程出过片的二创作品在新列表里也能用四步详情打开：分镜从参考视频拆解和当时的出片词、改编稿台词带过来，已出的片子是第 1 版。

接口见 `backend/API.md`「项目（新版，V10）」。验证：`ProjectFlowTest`（后端）和 `tests/projects.spec.ts`（页面，接口桩）。

## 原流程（交付项目里制作，仍可用）

1. 项目管理 → 新建交付项目：填写名称、负责人、截止、交付数量和需求。保存后自动进入项目。
2. 项目页 → 选择商品：整组图片显示为一个商品卡。没有商品时进入资源中心上传，并通过“返回项目”继续。
3. 核对商品事实：可打开已保存的商品分析，也可带入外观和质感作为待核对资料。广告建议和待验证功效不会自动作为事实使用；用户编辑并确认后才能继续。
4. 创建视频草稿：绑定项目、商品名称/SKU、素材ID、封面和分析版本；不提交视频生成。商品资料采用创建时快照，后续资源库变化不会自动覆盖作品。
5. 进入制作 → 生成本条分镜方案：使用当前文字模型或本地规则；镜头优先引用所选商品的素材，封面排在第一引用位置；分镜自动保存。可逐镜改画面、台词、时长和素材。
6. 确认方案 → 选择制作方式：本地粗剪或已配置的 Seedance 视频接口。外部视频仍需费用确认；目前接口按现有实现使用首个引用素材。
7. 提交 → 当前项目的生成任务 → 审片交付。可返回项目继续下一条，交付计数沿用真实文件及审核逻辑。

内容制作保留“直接做视频”快捷入口，增加“从项目开始（推荐）”。

验证：project-video-flow.spec.ts 通过 API 桩验证从创建项目到选择商品、事实确认、分镜保存、刷新恢复、提交以及项目范围任务列表的完整链路；不调用付费模型或生成真实视频。

## 视频二创模式（当前入口）

项目页“在此项目做视频”先弹出模式选择：剧情模式显示“后续开放”，视频二创模式进入 `/projects/{id}/remake`。

二创首版：上传或选择 REFERENCE 视频 → 播放/抽帧 → 标记时间与原片结构、声音参考及商品改编画面 → 保存拆解 → 选择商品、核对事实 → 创建二创作品 → 原有分镜确认/生成/审片。

- 当前是人工拆解，没有声称自动读片；不复制原片台词，不把参考视频自动用作成片素材。
- 首镜必须从0秒开始；切点递增、不重复、不越界；至少一镜、最多20镜。
- 分镜按原始各段占比分配目标时长，逐镜至少1秒，总和严格等于目标秒数。
- `creationMode=VIDEO_REMAKE`、来源素材ID/原始时间码/拆解快照存入作品config；实际镜头引用选中的商品素材。
- 保存拆解后刷新仍可按URL的reference恢复。原片拆解保存到参考素材，不覆盖商品分析。
- 新建交付项目默认目标交付数量为1，已有项目数量不变。

验证：2项测试覆盖时间分配/重复切点、真实可解码MP4播放、模式选择、保存后刷新恢复、商品选择、二创作品创建与项目范围任务页。模型和任务接口使用桩，不产生付费视频。

## 项目绑定商品

项目详情的“选择商品”从当前客户资源中心按整组选择，支持多选。V5 campaign_products 表保存项目与商品锚点的关联；GET /api/clients/{client}/campaigns/{campaign}/products 返回完整素材对象及 ProductAnalysisService 的最新分析（包括人工编辑、说明、版本、来源与过期状态）。不复制或重跑分析。

未绑定时提示先绑定商品，并禁用制作入口；直接访问二创页也拦截。绑定保存有项目版本校验，跨客户素材、非商品素材和归档项目不可绑定。取消勾选只移除项目关联，不删除原商品。

验证：后端集成测试覆盖整组返回、人工分析读取、持久化、去重、冲突、客户隔离及解绑保留原素材；页面测试覆盖未绑定禁用、直接访问拦截、绑定后刷新与下一步启用。

# 从项目开始制作视频

## 新版项目（2026-11，V10）

顶部「项目」栏目现在直接列项目：一个项目 = 一个商品 + 一种创作方式（就是原来的「作品」，`projects` 一行），不再经过交付项目。

1. 项目列表（`/`）：左栏文件夹（规则同商品库，最多两层），可搜索、改名、移动。新版建的项目（视频二创、框架模式、一键成片）都进新版详情 `/p/{id}`；旧流程里的框架模式、一键成片和其他作品进原来的制作页。
2. 新建项目（`/p/new`）：选商品（弹窗：左文件夹、右搜索，可在弹窗里新建商品并同步到商品库）→ 创作方式（视频二创 / 框架模式 / 一键成片，剧情模式即将开放）→ 视频二创选一条已拆解的参考视频（参考视频选择弹窗）→ 画幅（竖屏 9:16 / 横屏 16:9）、分辨率（480p / 720p / 1080p）、项目名、放进哪个文件夹 → 核对商品事实。不选发布平台和时长；创建不提交任何生成任务。参考视频详情的「用它新建项目」会带着这条视频进来。
3. 视频二创详情四步：商品 → 方向（参考视频的结构、开头类型、改编思路、给谁看——人群取自商品库）→ 分镜（每镜「原视频 | 改成」对照，改成的机位 / 画面 / 台词可编辑保存，台词可增删，每镜任务默认来自参考视频库的标注、可在这里改；顶部转化结构和广告用语检查都只提醒不拦）→ 出片。确认 / 下一步 / 出片按钮都在步骤条下方的置顶操作条里；分镜确认之前不出现成片画面。
4. 出片：确认后按分镜拼出分段出片词，走原来的任务提交和轮询（`jobs` / `JobWorker`），画幅和分辨率随任务快照传给视频接口。可出很多版：每版记下当时的出片词、画幅分辨率、改动说明；单独审片（好 / 差必填原因 / 可投放 / 不用了），「差」的原因自动带进下一版；「改这一版再出」可以一句话让 AI 改（需文字模型）或按段直接改；生成中显示真实阶段（排队 → 交给视频接口 → 生成中）和已等待时间，可取消；两版并排对比；「基于这条再做一条」四个入口（商品资料里没有价格时「换价格说法」不可用）。
5. 交付项目（`campaigns`）的数据和接口都保留，旧页面在 `/campaigns`、`/projects/{id}`；新建的项目不挂交付项目。旧流程出过片的二创作品在新列表里也能用四步详情打开：分镜从参考视频拆解和当时的出片词、改编稿台词带过来，已出的片子是第 1 版。

接口见 `backend/API.md`「项目（新版，V10）」。验证：`ProjectFlowTest`（后端）和 `tests/projects.spec.ts`（页面，接口桩）。

## 框架模式 / 一键成片（2026-11，V11）

和视频二创同一套四步、置顶操作条、右侧项目信息和多版本出片（`ModeDetail.tsx`、`StepDirections.tsx`、`StepDirBoard.tsx`，出片复用 `StepOutput.tsx`）。

- 框架模式：方向步先选给谁看（商品库的目标人群）和时长（只有 15 秒 / 30 秒），出 3 套方向。每套一张卡：开头类型（8 种之一）、前 3 秒怎么拍 / 怎么说、结构、卖点、场景，以及内容类型、节奏、人物、声音、片种、收尾这些格子；可以改格子（能恢复写出来时的原文）、单独重出一套、再出 3 套。打开「同时测几个方向」可以选 2~3 个（A/B/C），在顶部确认后每个方向各写一份分镜。分镜步按方向切换，顶部是转化结构条和这一档时长的骨架建议、台词检查（`adcheck`），画面和台词可编辑保存、逐镜恢复原文，方向改过会提示按新方向重写；逐份在顶部确认。出片步每个方向一条出片线（各自的版本、出片词、审片、改这一版再出、对比、接力），另有「对比几个方向」把每个方向最新的一版放在一起看（不放任何投放数字）。
- 一键成片：新建只建项目。出片步上面是出片设置（出发点：按商品资料 / 我有文案，时长 15 / 30 秒，给谁看，创意要求或文案；更多设置：出镜人物、台词和声音、节奏、片种）。顶部「开始出片 / 再出一版」确认后自动写 1 个方向和它的分镜再出片；设置没变时沿用现在（可能改过）的方向和分镜。方向、分镜两步可以回头看、可以改，不用逐步确认。每版卡片上列出出这一版时的设置，并写明和上一版的设置差别。
- 没有配置文字模型（`AI_MODE=local`）时：方向和分镜按商品理解拼本地模板，处处标“本地模板 · 不是 AI 写的”，缺的留空；不调任何外部模型。
- 没做：“我有脚本”出发点、产品线（电商信息流 / 品牌 TVC）、语速、配音配乐、前 3 秒多条备选和 AI 自评、一键成片转框架模式、任何投放数字。

接口见 `backend/API.md`「项目（新版）：框架模式 / 一键成片四步详情（V11）」。验证：`DirectionFlowTest`（后端，含 AI 路径的桩）和 `tests/direction-flow.spec.ts`（页面，跑在本机真后端的本地模式上）。

## 资产库和投放数据（2026-11，V12）

顶部「资产库」默认进 `/library`：所有项目出好的成片（每一版一条，`pages/library/`）。左栏：全部成片、分类方式、数据组（V14 起见下一节），14 种分类方式（商品、项目、创作方式、方向、开头类型、人群、场景、审片状态、评价、参考视频、时长、画幅、生成时间、投放数据），下面是以前的页面（样片广场、生成任务、审片交付、旧的投放数据、素材）。

- 列表：页头右侧「导入投放表格」「新建项目」；上面按商品、创作方式、审片状态、开头类型、人群筛选，按点击率 / 转化率 / 投产比排序（没填数据的排最后），只看填了数据的，搜索（也能搜视频编号、投放用名）。卡片用商品图做封面，标审片状态、该换新了、来源和三个投放数字（没填就写“还没填投放数据”）。
- 成片详情 `/library/{任务 id}`：播放成片、下载视频和字幕、审片（和项目里这一版是同一份）、投放数据（手填一条，表单的保存按钮在表单顶部；累计、点击率走势、每条记录改 / 删；该换新了的三个信号逐个写清数字）、基于这条再做一条（换开头 / 换场景 / 换人群 / 换价格说法，没有真实价格时最后一个灰着）、来源（商品、项目、方向、参考视频、开头、人群、场景、投放用名一键复制）、出片词。
- 接力：跳到 `/p/{项目}?step=4&relay=hook&from={这一版}`（框架模式带 `dir`），出片步打开这一版的「说一句话让 AI 改」并带上改法，参数用完就去掉；不会自动改写或出片。项目出片卡上的链接从「在生成任务里看」改成「在资产库打开」。
- 导入投放表格 `/library/import`：整页而不是弹窗（确认导入放在顶部操作条）。选 CSV（Excel 先另存为 CSV）→ 认出来的列可以改 → 逐行检查：能导入 / 有问题（写明原因，不导入）/ 没对上（手动指认或跳过）→ 顶部「导入能导入的 N 行」→ 结果里逐行说明没导的行。可以下载带投放用名的填写模板。
- 哪种赢了 `/library/win`、该换新了 `/library/tired`：只用填了数据的成片；没有数据就是空状态，不放示例数字。

接口见 `backend/API.md`「资产库与投放数据（V12）」。

## 投流数据回流（2026-11，V14）

资产库左栏「数据」组整合成：**投流看板** `/library/data/materials`（页签：素材维度 / 商品维度 / 账户维度 / 哪种赢了，`/library/data` 跳到素材维度）、**数据导入** `/library/data/import`、**投放建议** `/library/data/suggestions`（角标 = 待处理条数；页签里还有「该换新了」和「规则」）。旧地址 `/library/import`、`/library/win`、`/library/tired` 带着查询参数跳到新位置；旧的 `/analytics`（metrics 那套）路由不动。

- 成片命名：卡片下方和成片详情显示标准命名 + 「复制命名」，补不出来的写「未规范化」；详情里「改命名」只能改商品简称、内容形式、版本。
- 数据导入：先选千川账户和数据日期，再选 CSV；预览里逐行写明怎么对上的（命名 / 带后缀 / 前一截 / 素材 ID / 投放用名 / 视频编号 / 手动），没对上的可以搜成片手动关联或跳过；同一素材同一天再导是「更新这一天」。导完给出新增 / 更新 / 跳过行数和新建议条数。
- 素材维度：6 个汇总卡 + 12 列（点表头排序，每页 50 条），净 ROI ≥ 3 标绿、< 1 标红，1 小时退款率 > 30% 标红；筛选：日期、千川账户、商品、客户空间（就是右上角的客户，切换后数据按客户隔离）、创作者；导出 CSV（UTF-8 带 BOM）。商品维度只有 3 列和固定提示；账户维度分「数据看板 / 账户管理」。
- 成片详情多了「投放表现」：累计消耗 / 净成交 / 净 ROI / 平均 1 小时退款率 + 近 7 天净 ROI 走势（手写 SVG），没有千川数据就不显示；「查看完整数据 →」跳素材维度只看这一条。
- 投放建议：卡片写清建议类型、理由、触发时的数据和规则；接受 / 已执行 / 忽略只是记录，页面写明去千川后台操作。

接口见 `backend/API.md`「投流数据回流（V14）」。验证：`CampaignDataTest`、`CampaignDataPgTest`（设了 PostgreSQL 地址才跑）、`MigrationV14Test`、`ImportColumnsConfigTest`（后端）和 `tests/campaign-data.spec.ts`（A1–A8，跑在本机真后端上，A6 的完整流转另有一个拦截假接口的用例）。验证：`VideoLibraryTest`（后端）和 `tests/video-library.spec.ts`（页面：筛选 / 分组 / 哪种赢了 / 该换新了用拦截的假接口；手填、CSV 导入、接力跑在本机真后端上，测试写的记录会删掉）。

## 原流程（交付项目里制作，仍可用）

1. 项目管理 → 新建交付项目：填写名称、负责人、截止、交付数量和需求。保存后自动进入项目。
2. 项目页 → 选择商品：整组图片显示为一个商品卡。没有商品时进入资源中心上传，并通过“返回项目”继续。
3. 核对商品事实：可打开已保存的商品分析，也可带入外观和质感作为待核对资料。广告建议和待验证功效不会自动作为事实使用；用户编辑并确认后才能继续。
4. 创建视频草稿：绑定项目、商品名称/SKU、素材ID、封面和分析版本；不提交视频生成。商品资料采用创建时快照，后续资源库变化不会自动覆盖作品。
5. 进入制作 → 生成本条分镜方案：使用当前文字模型或本地规则；镜头优先引用所选商品的素材，封面排在第一引用位置；分镜自动保存。可逐镜改画面、台词、时长和素材。
6. 确认方案 → 选择制作方式：本地粗剪或已配置的 Seedance 视频接口。外部视频仍需费用确认；目前接口按现有实现使用首个引用素材。
7. 提交 → 当前项目的生成任务 → 审片交付。可返回项目继续下一条，交付计数沿用真实文件及审核逻辑。

内容制作保留“直接做视频”快捷入口，增加“从项目开始（推荐）”。

验证：project-video-flow.spec.ts 通过 API 桩验证从创建项目到选择商品、事实确认、分镜保存、刷新恢复、提交以及项目范围任务列表的完整链路；不调用付费模型或生成真实视频。

## 视频二创模式（当前入口）

项目页“在此项目做视频”先弹出模式选择：剧情模式显示“后续开放”，视频二创模式进入 `/projects/{id}/remake`。

二创首版：上传或选择 REFERENCE 视频 → 播放/抽帧 → 标记时间与原片结构、声音参考及商品改编画面 → 保存拆解 → 选择商品、核对事实 → 创建二创作品 → 原有分镜确认/生成/审片。

- 当前是人工拆解，没有声称自动读片；不复制原片台词，不把参考视频自动用作成片素材。
- 首镜必须从0秒开始；切点递增、不重复、不越界；至少一镜、最多20镜。
- 分镜按原始各段占比分配目标时长，逐镜至少1秒，总和严格等于目标秒数。
- `creationMode=VIDEO_REMAKE`、来源素材ID/原始时间码/拆解快照存入作品config；实际镜头引用选中的商品素材。
- 保存拆解后刷新仍可按URL的reference恢复。原片拆解保存到参考素材，不覆盖商品分析。
- 新建交付项目默认目标交付数量为1，已有项目数量不变。

验证：2项测试覆盖时间分配/重复切点、真实可解码MP4播放、模式选择、保存后刷新恢复、商品选择、二创作品创建与项目范围任务页。模型和任务接口使用桩，不产生付费视频。

## 项目绑定商品

项目详情的“选择商品”从当前客户资源中心按整组选择，支持多选。V5 campaign_products 表保存项目与商品锚点的关联；GET /api/clients/{client}/campaigns/{campaign}/products 返回完整素材对象及 ProductAnalysisService 的最新分析（包括人工编辑、说明、版本、来源与过期状态）。不复制或重跑分析。

未绑定时提示先绑定商品，并禁用制作入口；直接访问二创页也拦截。绑定保存有项目版本校验，跨客户素材、非商品素材和归档项目不可绑定。取消勾选只移除项目关联，不删除原商品。

验证：后端集成测试覆盖整组返回、人工分析读取、持久化、去重、冲突、客户隔离及解绑保留原素材；页面测试覆盖未绑定禁用、直接访问拦截、绑定后刷新与下一步启用。

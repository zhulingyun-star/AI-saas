# 视频二创：可编辑参考片分镜

本次接入当前使用的 `fronted/` + Java 后端（本地 8088），未修改 `xinliu/` 的独立工作台。入口：项目 → 视频二创 → 选择或上传参考视频 → AI 读取视频。

参考视频区域支持拖拽单个文件或点击上传，支持MP4/MOV/WebM、最大100MB。上传后自动选中并保存素材；上传期间拦截重复操作，多文件和不支持的格式会提示错误。

文件名旁提供删除按钮，确认后删除参考视频、对应分析/编辑记录及缩略图，并清空当前预览，可重新上传。正在排队/分析或被作品、历史任务引用的视频拒绝删除；此入口不能删除商品素材。分析确认弹窗只展示费用和处理范围，不展示模型名称。

## 行为

- 使用现有 AI 配置，通过 Gemini 原生 `/v1beta/models/{model}:generateContent` 的 Base64 `inlineData` 发送视频，不依赖 OSS。
- 本地 FFmpeg `scene > 0.4` 仅产生保守候选切点；时间用视频 PTS，不用模型估算时长。候选不等于真实切镜，也不以模型置信度自动删除候选。
- 整片原速＋候选表一次分析，分别填写动作/构图、机位、镜间衔接、镜内特效、花字、核对说明及整片结构/音乐。
- 对白字幕优先。只有报告无字幕语音区间时，才附加一次原速音频调用；音频结果只填指定空档，不覆盖已有字幕。营销花字和包装文字不能作为对白。
- 文字分三种独立数据：`dialogue`为对白字幕/无字幕语音；`Shot.text`仅为后期叠加花字；`Shot.productText`为瓶身、包装、衣物上的印字。品牌名按载体分类，不能仅因是品牌就当花字。旧报告缺少productText时显示“旧版画面文字（待分类）”，可一键移到产品文字；合并镜头、保存、补读采用均保留分类。
- 自动补读最多3个小于1秒的候选镜头，保留前后各约1秒画面。一次整片任务最多5次请求；超时或失败不自动重发。计费由供应商确定，UI先确认调用范围。
- 单镜可手动原速补读或3倍慢放无声复核。补读结果作为建议，不覆盖编辑；采用时只改内容，不改时间边界。拆分或合并改变目标区间后，旧建议不可继续采用。
- 支持横向缩略图、定位原片、连续镜合并、按播放位置拆分、编辑台词/时间/来源、保存与刷新恢复。镜间衔接、固定机位和特效是独立字段。
- 分镜保存与台词保存不触发模型调用或视频生成。带入旧商品改编入口仍保留人工商品改编确认；最多20镜，参考台词不自动作为商品成片台词。

## 接口和存储

V6迁移新增 `reference_storyboards`，以 `(client_id,asset_id)` 保存任务状态、修订号、报告、补读建议及本次调用耗时/usage。结果是参考素材级数据，同客户重复使用同一参考素材时共享。

- GET `/api/clients/{client}/assets/{asset}/storyboard`
- POST 同路径：`{revision,confirmed:true,shotId?:string,slow?:boolean}`；无shotId为整片，有shotId为补读。
- PUT 同路径：`{revision,report}`；乐观锁阻止旧版本覆盖，运行中禁止编辑。
- GET `/thumbnail?at=秒数`：鉴权后生成/缓存该参考片缩略图。
- DELETE `/api/clients/{client}/assets/{asset}/reference`：鉴权、CSRF及使用状态检查后删除参考素材和分析记录。数据库提交后清理原文件/缩略图；若文件系统清理失败，记录服务端清理日志，已删除素材不再可通过接口访问。

后台单线程任务：QUEUED → RUNNING → COMPLETED/FAILED。服务重启将RUNNING标失败，不自动重复收费；保留已完成结果。短镜补读失败时保留先前成功的整片报告。API验证客户归属、素材类型、时间轴连续性、ID唯一性、字段长度及台词来源。

任务请求JSON同步保存真实处理阶段、开始/结束时间；GET返回`progress.phase/elapsedSeconds/stageSeconds`。页面每2秒检查运行状态（含后台标签页），显示不确定进度动画和实际等待时间，不虚构百分比。POST受理状态立即写入查询缓存；首轮及补读报告变化均自动显示，未保存的手工编辑不会被轮询覆盖。首轮报告与补读落库时同时增加revision。支持旧后端报告变化而revision不变时的页面同步。

## 限制

- 第一版最多120秒、40个候选区间；超过20MB的模型输入先缩小为最长边720的H.264副本，仍超限则拒绝。原文件不修改。
- Gemini原生接口需要供应商支持；不能只看HTTP200就声称语义正确。输出仍须人工核对，复杂转场并未完成全面验收。
- 首轮每镜采用简洁字段，模型长输出可能触发网关超时；没有暗中降级为文本猜测，也没有自动重发。
- 缩略图是核对界面使用，不作为模型视频输入。慢放只用于视觉复核，台词和音乐保持原速。
- 参考片横竖屏不修改视频生成画幅。
